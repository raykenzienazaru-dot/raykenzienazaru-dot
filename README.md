An AI-powered web platform that helps users transform IoT ideas into interactive engineering prototypes.

IOTERA is designed as an early-stage engineering assistant that translates user ideas into technical requirements, recommends suitable components, and visualizes the proposed IoT system in an interactive 3D workspace.

Key Features

Machine Learning component recommendation

Text and voice input

Speech Recognition

IoT Component Library

Interactive 3D workspace

Add, move, rotate, and remove components

Basic pin, voltage, and compatibility validation

Project management and export workflow

🌱 AI VISION — Plant Disease Detection with TensorFlow Lite

A Computer Vision web application for testing a real TensorFlow Lite model before deployment to IoT devices such as ESP32-CAM.

The system performs image inference and classifies plant leaves into:

🌿 Healthy

⚪ Powdery

🟤 Rust

The project uses a real inference pipeline rather than simulated or hard-coded predictions.

System Architecture

Plant Image
     ↓
React Web Interface
     ↓
FastAPI Backend
     ↓
TensorFlow Lite Model
     ↓
AI Inference
     ↓
Healthy / Powdery / Rust

Tech Stack

Python • FastAPI • Uvicorn • TensorFlow Lite • NumPy • Pillow • React • Vite
